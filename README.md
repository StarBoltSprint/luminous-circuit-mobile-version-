- **Walk** the Hub, Light-Bridge, Canals, Foundry, Terraces, Soft Gates, Archive, Overlook, Join, Orchard, Wild Veins, Beacon, Howl Ring.
- **Howl** is civic gather. **Talk** a keeper. **Speak** is rare (your key, your meter).
- **Map** → tap a ward → **Ask** that keeper to grow their den.
